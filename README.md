
Learning log is a Django-based project that allows users to log a record of what they have learned online

Users input their topic of interest along with entries regarding what they have learnt about the topic, entries are time stamped and dated and can be edited at a later date 

Users are required to authenticate using Username and password -> adding email authentication can be another feature for the future 

This project taught skills in Django, creation of templates, the interaction been models, views and templates, urls, html and a brief intro to styling with Bootstrap
